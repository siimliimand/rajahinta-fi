# durable-source-governance-store — Tasks

> Ports the source-governance store to D1 so the operator console can actually grant merchants (alks staging grant is blocked on this today) and the ingestion gate reads durable state. Schema and repository first; the two consumers (ingestion compositions, console routes) rewire in parallel once the repository exists; docs and verification last. Nest backend keeps its in-memory store — out of scope.
