# Product Roadmap, Phases 1–4 — Tasks

> Ten roadmap features built on the existing Workers/D1/observation-log foundations. Each feature ships behind its own flag (default off). Most tasks go to `platform-engineer` (TypeScript, Hono, Drizzle/D1, React scope); `devops-engineer` covers environment declarations and observability for the new background job. `fullstack-engineer` is the primary planning agent, not a spawned worker. Cross-group schema tasks share `packages/data-platform/src/d1/schema.ts`, so they run sequentially even where no logical dependency exists.
> Feature order below mirrors the roadmap phases, not execution order: groups 1–9 are largely independent and parallelize once their schema tasks land.
